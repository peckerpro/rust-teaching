# Rust 教学编译器 - 需求清单

## 1. 编译器核心需求（分阶段实现）

### Phase 1: 最小可行编译器 (MVP)
| 模块 | 功能 | 教学价值 |
|------|------|----------|
| Lexer | 手写词法分析器，支持：关键字(let/fn/if/else/match/struct/enum/impl/mod/pub/use/return/loop/while/for/in/mut/ref/self/Self/as/move/unsafe/async/await)、标识符、整数字面量(10/16/8/2进制)、浮点、字符、字符串(raw/byte)、布尔、运算符、分隔符、注释(行注释/块注释/文档注释)、属性(#[]) | 状态机、正则等价、错误恢复 |
| Parser | 递归下降解析器，支持：表达式(运算符优先级)、语句、模式匹配、类型标注、函数定义、结构体、枚举、模块、use语句、泛型语法 | AST结构设计、Pratt解析、上下文敏感解析 |
| AST | 统一的AST节点类型，带源码位置信息(Span)，支持Debug/Pretty Print | 数据结构设计、访问者模式 |
| Semantic | 名称解析(Scope/Name Resolution)、简单类型检查(Type Check)、符号表(Symbol Table) | 作用域栈、符号表、类型推断基础 |
| IR Gen | 基于LLVM生成IR，支持：函数、基本块、控制流、简单表达式 | SSA、控制流图、LLVM IR理解 |
| Code Gen | 生成可执行文件 OR JIT执行 | 编译器后端原理 |

### Phase 2: 核心语言特性
| 类别 | 需支持的特性 |
|------|-------------|
| 类型系统 | 基本类型(i32/i64/f32/f64/bool/char/str)、元组、数组、切片、引用、裸指针 |
| 所有权 | Move语义、Copy trait、Drop |
| 借用 | &T 共享借用、&mut T 可变借用、借用规则检查(NLL简化版) |
| 生命周期 | 函数签名中的生命周期标注、生命周期省略规则(3条) |
| 控制流 | if/else、loop/while/for、match(含模式)、if let、while let |
| 函数 | fn定义、参数、返回值、语句/表达式区分、闭包(基础) |
| 结构体 | 具名结构体、元组结构体、单元结构体、方法(impl) |
| 枚举 | 基础枚举、带数据枚举、Option/Result |
| Trait | trait定义、impl实现、trait bound、derive宏(手工支持) |
| 泛型 | 泛型函数、泛型结构体、单态化(Monomorphization) |
| 模块 | mod、use、pub、模块树、路径解析(crate/self/super) |
| 宏 | 声明宏 macro_rules!(基础)，过程宏(教学说明) |

### Phase 3: 高级特性（教学演示级别）
| 特性 | 说明 |
|------|------|
| 模式匹配 | 穷尽性检查、ref绑定、@绑定、守卫 |
| 类型推断 | Hindley-Milner简化版、统一(Unification) |
| Trait对象 | dyn trait、虚函数表(vtable) |
| 错误处理 | ?操作符、From/Into转换 |
| 迭代器 | Iterator trait、适配器方法 |
| 智能指针 | Box/Rc/Arc(简化实现说明) |
| 并发 | Send/Sync marker trait、线程模型说明 |

## 2. 教学模块需求

### 2.1 可视化系统
| 功能 | 描述 |
|------|------|
| Token流展示 | Lexer输出彩色Token列表，标注行列号和类型 |
| AST树可视化 | 可折叠/展开的语法树，节点可点击查看详情 |
| 符号表展示 | 表格形式展示作用域嵌套、符号绑定关系 |
| 类型推导过程 | 逐步展示类型统一过程，动画效果 |
| 控制流图 | 基本块可视化，边标注分支条件 |
| LLVM IR展示 | 语法高亮的IR代码，与源码行对应 |
| 借用检查可视化 | 生命周期作用域图，冲突路径高亮 |

### 2.2 交互式功能
| 功能 | 描述 |
|------|------|
| REPL | 逐行输入Rust代码，即时编译和执行 |
| 分步编译 | 每个编译阶段可暂停，查看中间产物 |
| 代码对比 | 源码 vs AST vs IR 三栏对照 |
| 错误演练 | 故意引入错误，展示编译器如何检测和报告 |
| 性能分析 | 编译时间分析，各阶段耗时占比 |

### 2.3 课程体系
| 模块 | 主题 | 项目练习 |
|------|------|----------|
| 1 | 编译器概述与架构 | 搭建项目骨架 |
| 2 | 词法分析 | 实现扩展Lexer(新关键字/运算符) |
| 3 | 语法分析(上) | 实现表达式解析器 |
| 4 | 语法分析(下) | 实现语句/声明解析器 |
| 5 | 语义分析(上) | 实现符号表和名称解析 |
| 6 | 语义分析(下) | 实现类型检查器 |
| 7 | 所有权与借用 | 实现借用检查器 |
| 8 | 中间代码生成 | 实现LLVM IR生成 |
| 9 | 代码优化 | 实现简单优化Pass |
| 10 | 代码生成与运行时 | 实现完整编译流程 |

## 3. 微服务架构需求

### 3.1 服务拆分
```
┌─────────────────────────────────────────────────┐
│                  Nginx (反向代理)                  │
│               /api/* → API Gateway                │
└─────────────────────────────────────────────────┘
                         │
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   ┌──────────┐    ┌──────────┐    ┌──────────┐
   │Compiler  │    │Teaching  │    │  User    │
   │Service   │    │Service   │    │ Service  │
   └──────────┘    └──────────┘    └──────────┘
         │               │               │
         └───────────────┼───────────────┘
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
         PostgreSQL   Redis    MinIO(S3)
```

### 3.2 各服务职责

**Compiler Service (编译服务)**
- REST API: POST /compile - 提交编译请求
- WebSocket: /ws/compile - 实时编译过程推送
- 任务队列: 编译任务排队，支持超时和资源限制
- 沙箱执行: Docker沙箱中安全执行编译产物

**Teaching Service (教学服务)**
- 课程CRUD
- 习题管理(题目、测试用例、参考答案)
- 编译过程逐步展示接口
- 编译中间产物查询(AST/IR/SymbolTable)

**User Service (用户服务)**
- 注册/登录(JWT)
- 学习进度跟踪
- 提交记录

**API Gateway**
- 路由分发
- 认证拦截
- 限流
- 请求日志

## 4. 非功能性需求

| 类别 | 要求 |
|------|------|
| 安全 | Docker沙箱隔离编译执行、代码长度限制、CPU/内存限制、禁止网络访问 |
| 性能 | 简单代码编译<2秒, 编译中间产物缓存 |
| 可用性 | 各服务可独立部署和重启 |
| 可观测性 | 结构化日志、Prometheus指标、编译成功率/耗时统计 |
| 文档 | OpenAPI/Swagger接口文档、架构图、代码注释(中英双语) |
| 测试 | Lexer/Parser/Semantic单元测试覆盖率>80%、集成测试 |

## 5. 开发环境约束

- 宿主机: VMware Workstation + Ubuntu 24.04 Server
- 资源: 8GB RAM, 70GB 磁盘, 2×2(4) CPU核心
- 共享环境: 虚拟机还承担其他任务
- 用途: 代码编写 + 单元测试 + 集成验证（不承载生产流量）
